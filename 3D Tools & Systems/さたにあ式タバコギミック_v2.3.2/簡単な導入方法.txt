【動作環境】

Unity 2022.3.22f1
VRChat SDK Avatars 3.9.0 以上
Modular Avatar 1.12.5 以上
Non-Destructive Modular Framework 1.7.10 以上
lilToon 1.10.3 以上


【導入方法】
https://saturnianjp.github.io/satania_shopping_document/docs/SataniaTabako/Install/setup
に詳しく書いてあるので、ここでは簡潔に記しておきます！

-------------------------------------------------------------------------------------------------------------------

1. 必要なパッケージ
さたにあ式タバコは、基本的にModular AvatarとNDMFとlilToonが絶対に必要です。
VRChat用のUnityプロジェクトでないと動作しません。

MA、NDMF、lilToonの最新版を入れた上で使用してください。

VRChat SDK Avatars はv3.8.1以上にしてください。

-------------------------------------------------------------------------------------------------------------------

2.さたにあ式タバコを入れる
v1.x.xを使っている場合は、Assets内のさたにあしょっぴんぐ → Tabako System フォルダを削除してからインポートしないと、コンパイルエラーが発生して導入できないので注意してください。

Unityのプロジェクトに

	Satania Tabako Model and Textures.unitypackage
	Satania Tabako System v2.x.x.unitypackage

を入れないと、モデルが見えなかったり、正しく導入出来なかったりするので注意です。

-------------------------------------------------------------------------------------------------------------------

3.アバターに入れる
Unity上部のメニューから さたにあしょっぴんぐ → さたにあ式タバコ → さたにあ式タバコ導入ツール を開いてください。

その後にアバター (Avatar)にさたにあ式タバコを入れたいアバターを入れて、検索ワードに入れたいアバターの名前を入れてください。
対応アバターだと、対応プレハブが表示されるので、【アバターに入れる】ボタンを押すと導入完了です。

なにかわからないことがあれば、BOOTHのメッセージ機能からお問い合わせお願い致します。
