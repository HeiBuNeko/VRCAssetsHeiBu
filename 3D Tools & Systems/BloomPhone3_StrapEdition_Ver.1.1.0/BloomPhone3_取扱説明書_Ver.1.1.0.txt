■軽量版Prefab・ワールド用Prefabがあります！
機能をすべて搭載した通常のPrefabとは別に、カメラ、タイマー、フラッシュライト機能を
省いた軽量版Prefabをご用意しております。「見た目の改変に使用するのでギミックは要らない」
「アバターを軽くしたい」という方は軽量版のPrefabの使用をご検討ください。

また、ギミックを設定していないBloomPhone 3本体のモデルのみのPrefabもご用意しております。
装飾やワールドへの配置にご使用ください。


【導入方法】
※事前に、Unityプロジェクトへ Modular Avatar と lilToon を導入しておく必要があります。
※使用前にVRChat SDKのアップデートをお願いします。Ver.3.10.2以上でないと動作しません。

1.BloomPhone3のパッケージを、Unityのプロジェクトにインポートします。

2.Assets→SouWorks→BloomPhone3→Prefabとフォルダを開きます。
　次に、スマホを持たせる手が右手ならRightHand、左手ならLeftHandのフォルダを
　開きます。次に、軽量版を導入する場合はLite、通常版を導入する場合はStandardの
　フォルダを開き、その中のお好きな色のPrefabをアバターにドラッグ&ドロップで
　入れてください。

3.アバターに入れたPrefabを開き、「BP3_HandPosition」の位置、角度、大きさを
　調整して手に持った状態にしてください。この時に「BP3_HandPosition」以外の
　オブジェクトを動かさないでください。本体のみの場合は、これで導入完了です。

4.Prefab内にある「BP3_StrapPoint」を開き、その中の「BP3_Strap」を動かして
　ストラップの位置を調整します。ストラップの形をアバターに合わせる場合は、
　「BP3_Strap」の中にある「BP3_NeckStrap」を選択し、Inspectorからシェイプキーを
　調整してください。この時に「BP3_Strap」以外のオブジェクトを動かさないよう
　注意してください。ストラップの大きさはスマホ本体に合わせて自動調整されるため
　変更できません。


【ジェスチャー操作などのやり方】

■写真の撮影
カメラを起動した状態で、「RockNRoll」のジェスチャーをすると写真が撮れます。
再度撮影する際はメニューから撮影状態を解除してください。撮影はメニューから
でも行えます。「RockNRoll」のジェスチャーをすることで撮影する瞬間に表情が
変わって狙った表情にならない場合はセルフタイマーをご使用ください。

■ストラップと手持ちの切り替え
ストラップに掛かっているスマホを手に持つ際は、持つ方の手をスマホの位置に
合わせて「Fist」のジェスチャーをしてください。(スマホを掴むイメージ)
手に持ったスマホをストラップに掛ける際は、持つ時と同様にスマホを掛ける位置に
手を合わせて「Fist」のジェスチャーをしてください。
ストラップ、手持ちの切り替えはメニューの設定からでも行えます。
「Fist」の状態の手がストラップに当たった際に意図せず持ち替えてしまうことが
ありますので、ご注意ください。

■ワールド固定
スマホをワールド固定したい場所に合わせて、両手で「Fist」のジェスチャー
(両手を握る)をしてください。スマホがその場に固定されます。再び手に持つ場合は
持つ方の手を「Fist」のジェスチャーにした状態でワールド固定されているスマホに
当ててください。ワールド固定はメニューの設定からでも行えます。

■スワイプで画面切り替え
手で「Point」のジェスチャー(人差し指だけ伸びた状態)をした状態の人差し指で、
画面をしたから上にスワイプしてください。画面上部に反応する部分があるため、
上までしっかりスワイプしてください。スワイプ操作では、以下のように画面が
変化します。

画面OFF→ロック画面→ホーム画面→カスタム画面1→カスタム画面2→ホーム画面に戻り、以降ループ

■スマホ本体の角度・大きさの変更
スマホの上部を手で掴んで引っ張った方向に角度・大きさが変化します。引っ張った
状態でコントローラーのトリガーを押すとその状態で固定することができます。
ワールド固定した状態で引っ張る操作をした際に「Fist」のジェスチャーをすると
ワールド固定の解除動作と重なり手に移動してしまうことがあります。
引っ張る際は「Point」や「Gun」のジェスチャーで行うことをおすすめします。

■写真の保存・共有のやり方
カメラのメニューから保存モードを有効にした状態でVRChat標準のカメラをBloomPhone 3の画面中央に
重ねてください。こうするとBloomPhone 3で撮影した写真がVRChatのカメラに表示されます。
この状態で撮影することで、写真をPCに保存することが可能です。他のユーザーも同じように
保存ができるため、VRChatのカメラをかざしてもらうことで同じ写真を共有できます。

【各パーツのカラーの変更】
Assets→SouWorks→BloomPhone3→Materialとフォルダを開いてください。
「Body」「BackPanel」「Strap」のフォルダに本体、背面パネル、ストラップの
各カラーのマテリアルが入っています。お好きな色のマテリアルをモデルに
ドラッグ&ドロップで適用することで色を変更できます。


【背面パネルの変更】
アバターに入れたPrefabの中にある「BP3_BackPanelPoint」を開きます。
その中に現在付いている背面パネルがあるので、削除するか、Inspectorから非表示に
した上でTagをEditor Onlyにして非表示&アップロードされない状態にしてください。
その後、導入したい背面パネルのPrefabをドラッグ&ドロップで
「BP3_BackPanelPoint」の中に入れたら変更完了です。


【ケースの変更方法】
アバターに入れたPrefabの中にある「BP3_CasePoint」を開きます。
その中に現在装着されているケースがあるので、削除するか、Inspectorから非表示に
した上でTagをEditor Onlyにして非表示&アップロードされない状態にしてください。
(ストラップ無し版にはデフォルトでケースは付いていません) 
その後、装着したいケースのPrefabをドラッグ&ドロップで「BP3_CasePoint」の中に
入れたら変更完了です。


【ストラップにアクセサリーを付ける方法】(ストラップ付き版のみ)
アバターに入れたPrefabの中に「BP3_AccessoriesPoint」というものがあります。
この中に入れたオブジェクトはストラップの円形カラビナ部分に追従するので、
キーホルダーやカラビナ付きのワイヤレスイヤホンなどを入れることで
ストラップからぶら下げているように見せることができます。


【初期状態の変更】
アバターを読み込んだ時や、リセットした際の初期状態を変更できます。

アバターに導入したBloomPhone3のPrefabを選択し、Inspectorに表示される
「MA Parameters」を見てください。「BP3_Enable」や「BP3_Case」などの項目が
並んでいると思います。これらの項目の「初期値」と書いてある部分を変更します。
下記の項目が変更可能です。

「BP3_Enable」：初期値をOFFにすると初期状態ではスマホやストラップが
　　　　　　　　メニューで出すまで表示されなくなります。

「BP3_Position」：初期値をOFFにするとストラップがあっても最初から手持ち状態に
　　　　　　　　　なります。

「BP3_Case」：初期値をOFFにすると手持ちの時にのみスマホケースが表示されなく
　　　　　　　なります。メニューの設定から表示できます。

「BP3_SoundOff」：初期値をONにするとデフォルトでシャッター音やタイマーの
　　　　　　　　　アラームなどが鳴らない消音モードになります。
　　　　　　　　　メニューから解除できます。


【カスタム画面・壁紙設定】

■画面に表示する画像を用意する
データに付属しているPSDファイル(BP3_CustomDisplay.psd)を開くか、
任意の画像編集ソフトで付属の画面作成用マスク素材(BP3_DisplayMask.png)を
読み込んでください。画像内で透過されている範囲が画面に表示される領域に
なっているので、その範囲内に設定したい画像を収めて保存してください。
1024x1024のpng形式推奨です。保存した画像をUnityプロジェクトに
インポートして使用してください。

Assets/SouWorks/BloomPhone3/Texture/Wallpaperのフォルダ内に7種類の
壁紙が入っているので、そちらを使用していただいても大丈夫です。

■カスタム画面を設定する
Assets→SouWorks→BloomPhone3→Material→Displayとフォルダを開きます。
その中に「BP3_DP_Custom1」と「BP3_DP_Custom2」というマテリアルがあり、
これがカスタム画面1とカスタム画面2になっています。
変更したい画面のマテリアルを選択し、Inspectorに表示されるマテリアルの設定から
メインカラーのテクスチャを作成した画像に変更してください。
これでカスタム画面が変更されます。

■ロック画面、ホーム画面の壁紙を設定する
Assets→SouWorks→BloomPhone3→Material→Displayとフォルダを開きます。
その中に「BP3_DP_Home」と「BP3_DP_Lock」というマテリアルがあり、
これがホーム画面とロック画面になっています。
変更したい画面のマテリアルを選択し、Inspectorに表示されるマテリアルの設定から
メインカラーのテクスチャを作成した画像に変更してください。

壁紙の変更でロック画面やホーム画面の文字が見づらくなってしまった場合は、
文字の色を変更することができます。画面のマテリアルのメインカラー2ndが
UIのテクスチャになっており、このテクスチャを差し替えることで変更が可能です。
Assets→SouWorks→BloomPhone3→Texture→Home(またはLock)と開くと文字色が
白と黒のUIのテクスチャがあります。変更したい色のテクスチャを変更したい
画面のマテリアルのメインカラー2ndに差し替えてください。

ホーム画面のテクスチャには他言語のものが含まれておりますので、使用する言語の
ものをお選びください。

時計の色は、時計用のマテリアルで設定されているため、それを変更します。
Assets→SouWorks→BloomPhone3→Material→Displayとフォルダを開いてください。
その中の「BP3_Clock」が時計のマテリアルになっています。
「BP3_Clock」を選択した状態でInspectorに表示されるマテリアルの設定から
「Clock Color」の色を変更してください。


【言語設定】
BloomPhone3のメニューや画面UIはデフォルトで日本語表記になっていますが、
データを差し替えることで、以下の言語表示にも切り替えられます。

日本語 / 英語 / 韓国語 / 中国語（繁体字）/ 中国語（簡体字）

●ファイル名の言語表記
日本語：JPN
英語：ENG
韓国語：KOR
中国語（繁体字）：CHT
中国語（簡体字）：CHS

■メニューの言語変更
Assets→SouWorks→BloomPhone3→Menu→Normal(軽量版の場合はLite)とフォルダを
開くと、そこに各言語のメニューが入っています。
アバターに入れたBloomPhone 3のPrefabを選択し、Inspectorの下の方に表示される
「MA Menu Installer」の「プレハブ開発者向け設定」のタブを▶を押して開きます。
その中にある 「インストールされるメニュー」 に、変更したい言語のメニューを
入れるとメニューの言語が変更されます。
 
この時に通常版用のメニューと軽量版用のメニューを間違えないようご注意ください。

■画面UIの言語変更
Assets→SouWorks→BloomPhone3→Texture→AppDisplayとフォルダを開くと、そこに
各言語のUIのテクスチャが入っています。
Assets→SouWorks→BloomPhone3→Material→Displayとフォルダを開き、
その中にある「BP3_DP_App」がUIのマテリアルになっています。
「BP3_DP_App」を選択してInspectorに表示されるマテリアル設定から、
メインカラーを設定したい言語のUIのテクスチャに差し替えたらUIの言語が
変更されます。

■ホーム画面の言語変更
Assets→SouWorks→BloomPhone3→Texture→Homeとフォルダを開くと、そこに
各言語のホーム画面UIのテクスチャが入っています。
また、Assets→SouWorks→BloomPhone3→Material→Displayとフォルダを開き、
その中にある「BP3_DP_Home」がホーム画面のマテリアルになっています。
「BP3_DP_Home」を選択してInspectorに表示されるマテリアル設定の、
メインカラー2ndがホーム画面UIのテクスチャになっています。
このメインカラー2ndを設定したい言語のホーム画面UIテクスチャに
差し替えるとホーム画面の言語が変更されます。


【不具合が出る場合】
BloomPhone 3やアバター側に不具合が出る場合は、アニメーションの
「Write Default」設定による不具合である可能性が高いです。

Write Defaults(以下WD)とは、アニメーションで指定していない部分を
自動的に初期状態に戻すUnityの設定です。

BloomPhone 3に限らず、アバターにギミックを導入した際に起こり得る問題です。
原因は、WDをオンに設定しているアバターにWDオフのギミックを導入したり、
その逆を行うことでアバター内にWD設定のオン/オフが混在した状態になることです。
WDのオン/オフ混在は、VRChat公式でも避けるようアナウンスされており、混在すると
WDに依存しているアニメーションが動かなくなったり、WDオフ前提のアニメーションが
正しく動作しなくなることがあります。

BloomPhone 3はVer.1.1.0以降ではWDのオン/オフに関わらず動作する仕様に
なっております。Modular Avatarの設定により、アバター側のWD設定に自動的に
合うようになっているため、不具合は起こりにくいです。
しかし、BloomPhone 3導入前からアバター内がWDのオン/オフが混在した状態である場合、
Modular Avatarがアバター側のWD設定がどちらなのか判定できず、アバターと違うWD設定で
導入されてしまう可能性があります。

BloomPhone 3を導入後に不具合が起きた場合は、アバター側のWD設定がオン/オフ混在した
状態になっていないかご確認ください。混在している場合は、WD設定を統一するツール等を
使用して、オンかオフのどちらかに設定を合わせてから導入をお試しください。

WD設定の変更はアバターの動作に影響するため、作業の結果アバターに不具合が出る
可能性がございます。必ずバックアップを取ってから作業を行ってください。


【アップロードに失敗する場合】
BloomPhone 3を導入後にアバターのアップロードに失敗する場合は、
同期パラメーター数が上限を超えている可能性が高いです。

BloomPhone 3は搭載しているギミックの関係上、ストラップ付きの全機能入った
Prefabで同期パラメーターを53使用します。(軽量版は13に抑えています)
VRChatのアバターは同期パラメーターを256までしか持つことができません。
そのため、既に多くのギミックを導入済みで同期パラメーターを多く使用している
アバターでは、BloomPhone 3を導入することで上限を超えてしまいアップロード
できなくなる場合があります。

対処法は以下の通りです。

・BloomPhone 3の軽量版を使用する。機能が削減された分パラメーター数が13に
　抑えられています。
　
・既にアバターに導入されいる他のギミックを削除する。BloomPhone 3の全ての機能を
　使用する場合は、恐縮ですが他のギミックを削除していただくしかありません。
